# Mushroom v0.5.0 — DRAFT

**Released:** _pending_ · **Milestone:** 05 — AI search

> This is the release the whole thing was for. Ask Mushroom a question in
> ordinary words about something you wrote down and forgot, and it finds the
> passages, answers from them, and shows you which notes it used.

## What's new

- `Ctrl+Shift+F` opens AI Search. Type a question, press `Ask Mushroom`.
- Mushroom searches your notes locally first, shows you which ones it found,
  then asks the model using only those passages as context.
- The answer streams in as it is written, with a blinking block caret.
- **Every answer lists its sources.** Click one and the note opens at the
  passage the answer came from. Citation markers in the answer text are
  clickable too.
- A collapsed `Also searched` list shows what else was retrieved but not used,
  so you can see what Mushroom considered.
- `Stop` cancels a request mid-answer, and actually aborts it rather than
  throwing away the result.
- If Mushroom cannot find anything relevant, it says so and tells you what it
  searched for — it does not call the model and it does not guess.
- Your last twenty questions are in a drop-down.
- Token usage for the last request shows in the status bar.

## Honesty, specifically

The point of Mushroom is retrieval, not conversation, so the answer is
constrained:

- The model is told to answer **only** from the supplied excerpts, to cite
  them, and that "I could not find this in your notes" is a correct answer.
- Mushroom checks the citations afterwards. If the model cites something that
  was not supplied, the answer carries a warning. If it cites nothing at all,
  the answer is marked unverified rather than presented as sourced.
- The text of each excerpt that was sent is shown next to its source, so you
  can see what the model actually had to work with.
- Each question retrieves fresh. There is no conversation memory carrying a
  previous answer forward as if it were fact.

## What doesn't work yet

- **Retrieval is keyword-based.** If your question uses different words from
  your notes, Mushroom may not find the right passage — and then it will
  honestly say it found nothing rather than invent something. Semantic search
  is spec 07, deliberately after 1.0.
- No quick open, no external-change detection, no diagnostics screen yet.
  Milestone 06.
- Mushroom cannot write or edit notes, summarise your whole vault, or take any
  action on its own. Not planned.
- The installer is unsigned.

## Under the hood

- The pipeline is question → search terms → retrieval → context → prompt →
  model → citation resolution, and every stage except the two behind traits is
  a pure function. The whole thing is testable without a network or a
  database.
- Question words and stop words are stripped mechanically before searching,
  not by asking a model to rewrite the query — that would double the latency
  and cost of every question and would mean talking to the network before
  searching locally.
- The context budget drops whole excerpts from the lowest-ranked end. It never
  truncates one mid-sentence, because half a sentence is exactly the kind of
  context that produces a confident wrong answer.
- Retrieval uses the same path as the search box, so both see identical
  results for the same query.
- The system prompt is a Markdown file in the repository, not a string buried
  in Rust, so it can be read and changed without recompiling.
