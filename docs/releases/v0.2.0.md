# Mushroom v0.2.0 — DRAFT

**Released:** _pending_ · **Milestone:** 02 — Notes

> Mushroom can now hold notes. Write, save, organise into folders, preview,
> and delete — and every note is a plain Markdown file in a folder you can open
> with anything else.

## What's new

- Create, edit, save, rename, move, and delete notes. `Ctrl+N` and `Ctrl+S`
  do what they should.
- Notes live in `%USERPROFILE%\Mushroom\notes`, as ordinary `.md` files, in
  folders you control. Nothing is locked inside the application.
- The notebook pane browses folders; the notes list shows what is in them,
  newest first, grouped by date.
- Markdown preview with headings, lists, links, code, quotes, and tables.
  Edit, Preview, and Split views.
- Autosave three seconds after you stop typing, and on switching notes,
  losing focus, or closing.
- Deletes go to `.trash` inside the notes folder and can be restored. Deleting
  asks first, and Cancel is the default.
- Links between notes work — relative `.md` links and `[[wikilinks]]`. External
  links open in your browser.
- Import a folder of existing Markdown; export notes back out.

## What doesn't work yet

- **No search.** You can browse but not search. Milestone 03 — and it is the
  next thing.
- **No AI.** Milestones 04 and 05.
- Mushroom does not notice if you edit a note in another program while it is
  open. It checks on save and asks before overwriting, but it will not
  live-reload. Milestone 06.
- The editor is a plain text area: no syntax highlighting, no line numbers.
  Deliberate for now.
- The installer is unsigned.

## Under the hood

- A note's identity is its path relative to the notes root. No UUIDs, no
  sidecar files, nothing that makes the folder less portable.
- Saves are atomic: temp file, flush, rename. A crash mid-save leaves the old
  file or the new one, never half of one.
- YAML frontmatter round-trips — Mushroom owns `title`, `created`, `updated`,
  and `tags`, and leaves every other key exactly as it found it.
- Your Markdown is never reformatted. Line endings, trailing whitespace, and
  tabs come back the way you wrote them.
- The note list is scanned once at startup and cached; it is not re-read on
  every click.
