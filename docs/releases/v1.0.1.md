# Mushroom v1.0.1

**Released:** 2026-09-18 · **Milestone:** 06 — Polish & packaging

> A one-line fix to the uninstaller, found half an hour after 1.0.0 shipped by
> running the thing rather than trusting it.

## Fixed

**The uninstaller could hang, and said the wrong thing during an upgrade.**

v1.0.0 added a message shown before uninstalling, saying that your notes are
not removed and where they are. That message is worth having — but it was shown
*unconditionally*, and two things run the uninstaller without anyone watching:

- **`uninstall.exe /S`** — a silent uninstall, used by deployment tooling and
  scripts. A modal dialog there does not annoy anybody; it hangs forever,
  invisibly, because there is nobody to click OK.
- **Installing a newer version.** The installer runs the existing uninstaller
  with `/UPDATE` first. So upgrading *from* 1.0.0 would have stopped to
  reassure you that your notes were safe from a removal that was not
  happening — and a silent upgrade would have hung.

The message now appears only for an uninstall a person started and is watching.
Nothing else changed.

## If you have v1.0.0 installed

Upgrading to 1.0.1 works normally: **click through the "your notes are NOT
removed" dialog** if it appears — it is 1.0.0's uninstaller talking, and your
notes really are safe. After this release that prompt is gone from the upgrade
path for good.

If you are upgrading silently (`Mushroom_1.0.1_x64-setup.exe /S`) from 1.0.0,
uninstall 1.0.0 by hand first, or the install will wait on a dialog you cannot
see.

## Everything else

Unchanged from [v1.0.0](https://github.com/travisdng/mushroom/releases/tag/v1.0.0)
— the measured numbers, the known gaps and the verification all still stand.

## Install

- `Mushroom_1.0.1_x64-setup.exe` — per-user, no admin rights.
- `Mushroom_1.0.1_x64_en-US.msi` — machine-wide.
- Unsigned; SmartScreen will warn. Do not disable SmartScreen — choose
  "More info" then "Run anyway" if you trust the build, or build it yourself
  from source.
